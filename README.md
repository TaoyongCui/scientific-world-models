# Scientific World Models — ICLR 2027

Scientific World Models: From Prediction to Intervention and Discovery

Website: https://taoyongcui.github.io/scientific-world-models/

A static, responsive workshop website based on the latest workshop proposal. The visual style follows [Lifelong Agents](https://lifelongagent.github.io/#organizers): Raleway/Open Sans typography, a navy city banner, red accents, circular portrait grids, and a striped schedule table.

## Editing

- Edit `index.html` for workshop copy, dates, participant information, and the program.
- Edit `assets/css/style.css` for layout and colors.
- Edit `assets/js/main.js` for navigation behavior.
- Participant portraits are in `assets/img/people/`.
- Source attribution and font licenses are linked from `credits.html`.

The website is marked as a workshop proposal. The contribution deadline and program reflect the proposed plan. Add the real OpenReview submission URL and allocated workshop date once announced; update the proposal status after the decision.

## Preview

From this directory, run `python3 -m http.server 8000` and open `http://localhost:8000`.

## Publishing

GitHub Pages publishes the root of the `main` branch. `.nojekyll` enables direct static-file serving. No package installation or build is needed. All portraits, fonts, and figures are served from this repository.
